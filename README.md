# Boing Network organization

This public `.github` repository is the **organization profile and default community-health home** for [Boing Network](https://github.com/Boing-Network).

It is **not** one of the four official product repositories. Those are:

| Repository | Product |
|---|---|
| [boing.network](https://github.com/Boing-Network/boing.network) | L1 protocol, node, SDK, website |
| [boing.observer](https://github.com/Boing-Network/boing.observer) | Explorer |
| [boing.express](https://github.com/Boing-Network/boing.express) | Wallet |
| [boing.finance](https://github.com/Boing-Network/boing.finance) | DeFi |

## What this repo provides

| Path | GitHub feature |
|---|---|
| [`profile/README.md`](profile/README.md) | Organization cover page on [github.com/Boing-Network](https://github.com/Boing-Network) |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Default code of conduct for org repos that do not define their own |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Default contribution guide (routes to the right product repo) |
| [`SECURITY.md`](SECURITY.md) | Default security policy and private disclosure path |
| [`SUPPORT.md`](SUPPORT.md) | Default support channels |
| [`GOVERNANCE.md`](GOVERNANCE.md) | How the organization is run |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | Default issue forms |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Default pull request template |
| [`.github/DISCUSSION_TEMPLATE/`](.github/DISCUSSION_TEMPLATE/) | Discussion forms for this community hub |

Product-specific docs, CI, and code stay in the four official repositories. Override any of these defaults by adding the same filename in a product repo.
